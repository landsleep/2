# Project Bullet Guidance

Use this reference when rewriting project, research, data, software, engineering, finance, or product bullets.

## Strong Project Bullet Pattern

Use:

`Built/Analyzed/Designed/Optimized + artifact/method + data/system/context + result/use`

Examples of useful detail:

- Tools: Python, R, SQL, Excel, Stata, MATLAB, PyTorch, scikit-learn, Tableau, Power BI
- Methods: regression, forecasting, classification, causal inference, optimization, NLP, time series, simulation
- Data scope: observations, variables, period, frequency, source type
- Output: dashboard, model, report, paper, pipeline, API, prototype, recommendation
- Impact: accuracy, runtime, cost, adoption, decision support, publication, stakeholder use

## If Metrics Are Missing

Use defensible non-numeric specificity:

- "daily transaction data"
- "multi-source macroeconomic indicators"
- "rolling-window forecasts"
- "cross-functional stakeholder report"
- "reproducible analysis pipeline"

Ask for metrics only when they would materially improve the resume.
