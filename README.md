# resume-generator

一个用于生成、润色、定制和排版简历的 Codex Skill。支持中文、英文、双语简历，适用于求职简历、学术 CV、岗位定制和可编辑 Word 简历交付。

它不仅修改文字，还提供一套“先看视觉效果，再交付可编辑文档”的完整工作流。

## 核心工作流

当用户要求制作美观的 Word 简历时，`resume-generator` 按以下步骤工作：

1. **润色真实内容**：梳理目标岗位、教育经历、工作或实习经历、项目、科研、技能和荣誉，不编造经历或数据。
2. **用 ChatGPT 生图生成 3 套完整风格稿**：三套图片都直接包含用户提供并润色后的真实个人信息与正文，不使用空白模板、伪文字、排版线条或后期叠字。
3. **用户挑选喜欢的版式方向**：默认提供商务简约、轻奢蓝灰、创意清新三种方向，可继续调整颜色、信息密度、是否放照片、一页或两页等。
4. **用真实文本复刻为可编辑 Word**：按照选中的视觉方向，用真实文字、段落、表格和样式重建，不把整张预览图塞进 Word。
5. **渲染 Word 预览并确认**：检查分页、字体、日期对齐、文字裁切、重叠和照片比例。
6. **交付 `.docx`**：用户确认后提供可继续修改的 Word 文档；需要时也可同时提供 PDF 或 LaTeX 版本。

```text
原始经历 → 内容润色 → AI 风格稿 → 用户选版
        → 真实文本重建 → Word 渲染检查 → 可编辑 DOCX
```

## 内置风格

默认生成以下三套完整、有真实文字的 ChatGPT 简历风格稿：

### 1. 商务简约

- A4 竖版，黑白灰配色和现代无衬线字体
- 专业正式、ATS 友好，适合法务、工程、运营和行政岗位
- 紧凑但不拥挤，以细分割线和精确日期对齐组织信息

### 2. 轻奢蓝灰

- A4 竖版，低饱和度蓝灰配色和克制的编辑式网格
- 细微线条分割板块，适合金融、咨询、证券和公司法务岗位
- 强调秩序、层级和高级感，不使用夸张装饰

### 3. 创意清新

- A4 竖版，淡青与白色配色
- 使用少量几何元素和柔和圆角，适合设计、新媒体、品牌和产品岗位
- 保持专业阅读效率，不做成信息图或卡片式仪表盘

三套风格都必须合理利用页面空间。页面下半部分不得出现无意义的大面积空白；内容较多时，优先使用均衡的两页版。

## 一份完整简历通常包括什么

不同行业会有所增减，但一份结构完整的求职简历通常包含：

### 1. 个人信息

- 姓名
- 电话、邮箱、所在城市
- 求职方向或目标岗位
- 个人主页、GitHub、作品集或学术主页（如适用）
- 证件照（可选，应由用户决定）

### 2. 个人概述

用 2-4 行说明专业背景、经验方向和核心优势。应包含可验证的定位信息，避免“认真负责、学习能力强”等空泛表述。

### 3. 教育背景

- 学校、专业、学历
- 起止时间
- GPA、排名、核心课程
- 奖学金和重要荣誉

### 4. 工作或实习经历

每段经历建议写明：

- 公司或机构、部门、职位、时间
- 负责的任务和业务场景
- 使用的方法、工具或技术
- 可以验证的成果、规模或影响

推荐使用：`行动 + 方法/工具 + 场景 + 结果`。

### 5. 项目或科研经历

- 项目名称、角色、时间
- 研究或业务目标
- 个人承担的工作
- 数据、工具、方法和最终产出
- 论文、报告、奖项、系统或可量化结果

### 6. 专业技能

按岗位相关性分组，例如：

- 专业工具或软件
- 编程语言与数据工具
- 临床、实验或工程技能
- 语言能力
- 职业证书

技能应尽量能被前面的经历证明，不建议使用没有依据的熟练度进度条。

### 7. 可选模块

- 论文与专利
- 竞赛与荣誉
- 校园实践与志愿经历
- 作品集
- 专业证书
- 学术会议与公开演讲

## 预览阶段会生成什么

| 阶段 | 输出 | 用途 | 是否为最终内容 |
| --- | --- | --- | --- |
| 内容润色 | Markdown 或结构化文本 | 确认事实、顺序和表达 | 是 |
| 3 套 AI 风格稿 | PNG 图片 | 选择视觉方向 | 是，必须使用真实个人信息与正文 |
| 可编辑版式预览 | Word/PDF 渲染 PNG | 检查真实文本与排版 | 是 |
| 最终交付 | `.docx` | 编辑、投递、打印 | 是 |
| 可选交付 | `.pdf` / `.tex` | 固定版式或 LaTeX 编辑 | 是 |

## 使用示例

### 润色现有简历

```text
用 resume-generator 润色这份简历，目标岗位是机械结构工程师。
保留真实经历，不要虚构指标。
```

### 先生成风格稿，再制作 Word

```text
用 resume-generator 把这份简历做成美观大方的 Word。
先用 ChatGPT 生图生成三套带真实文字的完整风格稿，等我选择后再制作可编辑 DOCX。
```

### 根据岗位描述定制

```text
根据下面的岗位 JD 调整我的简历，提取关键词并重排经历。
只使用我提供过的事实，最后生成一页 ATS 友好的版本。
```

### 制作中英文版本

```text
把这份中文简历改成自然、专业的英文简历。
不要逐字翻译，保持经历与数据一致。
```

## 设计与内容原则

- 不编造公司、学历、日期、项目、论文、证书或量化结果。
- 三套生图风格稿必须直接使用真实个人信息和真实正文，不允许空白底稿、后期叠字、伪文字或虚构履历。
- 每套风格稿展示前都要核对事实和文字；不合格的图片不计入三套候选。
- 页面应紧凑但不拥挤，避免无意义的大面积空白。
- 优先保证信息层级、阅读效率和岗位相关性。
- 中文求职简历通常优先使用 A4；应届生通常控制在 1 页，内容较多时可使用 2 页。
- 保持联系方式、标题、经历和技能可被 ATS 读取。
- 正式投递前必须检查拼写、日期、联系方式、证件照和文件名。

## 安装

将仓库克隆到个人 Codex Skills 目录：

```bash
git clone https://github.com/From-zero-tohero/resume-generator.git ~/.codex/skills/resume-generator
```

重新启动或刷新 Codex 后，即可在对话中调用：

```text
用 resume-generator 帮我优化这份简历。
```
